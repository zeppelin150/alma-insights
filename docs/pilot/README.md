# Enablement Pilot — Document Package (Jul 20 – Aug 14, 2026)

Single-user, four-week pilot of the Alma Insights enablement experience
(Content Command Center). Both files are formatted for direct upload to
Google Drive (Docs/Sheets import them cleanly).

| File | What it is |
|------|------------|
| `Alma_Insights_Enablement_Pilot_Overview.docx` | Program overview & test plan: what Alma Insights is, what CI/CD is, the four test tracks, the week-by-week timeline, measurement plan, build-while-testing operating model, roles, success criteria, risks, Week-1 setup checklist, and both survey question sets (Appendices A–C). |
| `Alma_Insights_Pilot_UAT_Tracker.xlsx` | Week-over-week UAT workbook: README + rubric, Features & Searchability Scorecard (4 dimensions × 4 weeks), prefilled test-case tabs for Weeks 1–4, Bug Log, CI/CD Update Log, and Pre-/Post-Launch Survey tabs. Yellow cells are the fill-ins; example rows in the logs are marked EXAMPLE. |

Week map: **W1** setup & onboarding · **W2** core workflows (Asana / Guru /
Renn / Drive search) + Zendesk emulation via Drive mirror + first auto-update ·
**W3** Slack (if approved) + full-suite · **W4** polish, regression, readout.
CI/CD auto-updates, bug management, and stability run continuously from W2.
Zendesk is deliberately **not** connected — macros and Support Center content
are mirrored into a Drive folder (EC-bootstrap pattern) and results are
copy-pasted, keeping the pilot PHI-airgapped.
